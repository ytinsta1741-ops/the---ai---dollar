Drop licensed background tracks in this folder (.mp3 / .wav / .m4a).

One is picked at random per video, looped to length, and faded in/out.
If this folder is empty, the pipeline falls back to the synthesised bed.

USE ONLY MUSIC LICENSED FOR COMMERCIAL USE. Safe free sources:
  - YouTube Audio Library  studio.youtube.com -> Audio library
  - Pixabay Music          pixabay.com/music
  - Uppbeat (free tier)    uppbeat.io
  - Free Music Archive     freemusicarchive.org  (check each licence)

Do NOT put chart/trending songs here. YouTube Content ID will claim or
block the upload and Instagram mutes copyrighted audio in an uploaded
file. To use an actual trending sound on Instagram, add it in the
Instagram app's own audio picker after posting - Meta licenses it there.
